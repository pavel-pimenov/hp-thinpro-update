# HP ThinPro Update

Простой сайт на Python (Flask) в Docker Compose для **выгрузки и раздачи обновлений HP ThinPro**.

У HP внутри `ftp.hp.com` листинги каталогов почти везде отключены, так что прямой
зеркальный обход невозможен. Но известные индексы доступны:

- `http://ftp.hp.com/pub/tcimages/EasyUpdate/Images/hpcatalog.xml` — образы ОС;
- `http://ftp.hp.com/pub/tcimages/EasyUpdate/Images/addoncatalog.xml` — аддоны/пакеты.

Сайт парсит эти индексы, показывает список и умеет:

- **проксировать** файл напрямую с HP (стриминг, поддержка Range/докачки);
- **точечно выгружать** выбранные файлы на свой сервер в фоне (кнопка «Зеркало»),
  после чего они раздаются уже из локального кэша;
- **массово зеркалить всё по версии** ThinPro (8.0/8.1/9.0) — создать локальный
  оффлайн-репозиторий пакетов одной кнопкой.

По умолчанию отфильтрованы **Windows** (Smart Zero Core и Windows IoT) и **i386** —
остаётся только **ThinPro 64-bit (amd64)**. См. `THINPRO_ONLY` / `LINUX_ONLY`.

## Быстрый старт

```bash
cp .env.example .env   # при необходимости
docker compose up -d
# сайт: http://localhost:8080
```

При первом запуске каталоги скачаются сами в фоне (нужен доступ к `ftp.hp.com`).
Если хочется сразу — откройте главную и нажмите **«Обновить каталоги»**.

## Как это работает

```
ftp.hp.com  (каталоги + файлы)
    │
    ▼
hpcatalog.xml / addoncatalog.xml  ──(парсинг, ThinPro-фильтр)──►  index.json
    │                                                        (data/index.json)
    ▼
http://ваш-сервер:8080
    ├── /images   — образы ОС ThinPro (только T-образы)
    ├── /addons   — пакеты/аддоны, сгруппированы по версии ThinPro
    ├── /file/...        — «Скачать»  → стриминг с HP (или из кэша)
    ├── /mirror/...      — «Зеркало»  → фоновая выгрузка файла на сервер
    └── /mirror_all/…    — «Зеркалить всё» → оффлайн-репозиторий версии
```

Файлы, скачанные кнопкой «Зеркало», складываются в каталог кэша
(`CACHE_DIR`, по умолчанию `data/mirror`) и дальше раздаются уже оттуда —
внутренним клиентам не приходится ходить на HP.

## Маршруты

| Путь | Описание |
| --- | --- |
| `/` | Главная: обновить каталоги, статистика, сырые XML |
| `/images` | Образы ОС ThinPro, фильтры по платформе и поиску |
| `/addons` | Пакеты ThinPro, сгруппированы по версии, фильтры |
| `/debs` | Все пакеты Debian (.deb) для оффлайн-установки на клиентах |
| `/xars` | Все сервис-паки HP (.xar) для оффлайн-установки на клиентах |
| `/mirror_all/<version>` | POST: массовое зеркалирование всех файлов версии |
| `/mirror_all_debs` | POST: массовое зеркалирование всех .deb |
| `/mirror_all_xars` | POST: массовое зеркалирование всех .xar |
| `/cancel/<job_id>` | POST: остановить массовое зеркалирование |
| `/jobs` | Прогресс точечной и массовой выгрузки |
| `/file/<catalog>/<row>/<file>` | Скачивание (прокси или кэш), Range поддерживается |
| `/mirror/<catalog>/<row>/<file>` | POST: запустить фоновую выгрузку файла |
| `/catalogs/<name>.xml` | Сырой скачанный каталог |
| `/api/index.json` | Весь индекс каталогов в JSON |
| `/healthz` | Healthcheck |

## Конфигурация (переменные окружения)

| Переменная | По умолчанию | Описание |
| --- | --- | --- |
| `UPSTREAM_BASE` | `https://ftp.hp.com` | Базовый адрес HP (можно свой прокси/зеркало каталогов) |
| `DATA_DIR` | `/data` | Куда складывать каталоги и индекс |
| `CACHE_DIR` | `$DATA_DIR/mirror` | Куда выгружать файлы («Зеркало»), пусто = только прокси |
| `ENABLE_MIRROR` | `true` | Отключить зеркалирование совсем |
| `MAX_CONCURRENT_MIRRORS` | `4` | Сколько файлов качать на сервер одновременно |
| `REFRESH_INTERVAL_HOURS` | `12` | Автообновление каталогов, часы |
| `THINPRO_ONLY` | `true` | Только ThinPro (скрывает Smart Zero Core и Windows) |
| `LINUX_ONLY` | `true` | Иметь в виду если `THINPRO_ONLY=false` — скрывает Windows |
| `PORT` | `8080` | Порт на хосте (в контейнере всегда 8000) |
| `SECRET_KEY` | — | Секрет сессий, поменяйте для прода |
| `HTTPS_PROXY` / `HTTP_PROXY` | — | Прокси для исходящих запросов к HP |

## Запуск без Docker (для разработки)

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
UPSTREAM_BASE=https://ftp.hp.com DATA_DIR=./data flask --app app run --port 8000
```

## Ручное обновление каталогов вне контейнера (cron)

```bash
# каталоги скачаются и распарсятся в DATA_DIR при следующем старте сайта,
# либо просто держите приложение работающим — оно обновляется само.
```

## Важно

- Кнопка «Зеркало» / «Зеркалить всё» качает файлы целиком (образы — единицы ГБ).
  Убедитесь, что на диске хватает места, иначе задача завершится с ошибкой
  «размер не совпал».
- Массовое зеркалирование версии качает по очереди с `MAX_CONCURRENT_MIRRORS`
  одновременными потоками; прогресс можно наблюдать на `/jobs` и остановить
  кнопкой «Отменить».
- Если HP перестал быть доступен, кэшированные файлы продолжают раздаваться из
  локального каталога.
- Проверка целостности зеркала: размер скачанного файла сверяется с размером из
  каталога; при несовпадении задача помечается ошибкой.
